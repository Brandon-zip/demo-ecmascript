### Directorio Corporativo - Demo ECMAScript
Este proyecto es una demostración técnica de la implementación del estándar **ECMAScript (JavaScript moderno)**, desarrollado como ejemplo práctico para la exposición de estándares web de la Universidad Politécnica Salesiana.

### Live Demo
Puedes ver el proyecto funcionando en vivo aquí: https://brandon-zip.github.io/demo-ecmascript/

### Objetivo
El propósito de este código es evidenciar el uso de asincronía moderna y manipulación del DOM sin depender de librerías externas o transpiladores, aplicando las buenas prácticas de las especificaciones ES6 y ES8.

### Características de ECMAScript implementadas

*   **`async / await` (ES8):** Manejo del *Event Loop* y operaciones asíncronas para evitar el bloqueo del hilo principal (*Single Thread*) de la interfaz de usuario.
*   **Fetch API:** Consumo nativo de datos externos (API REST), reemplazando el antiguo `XMLHttpRequest`.
*   **Manejo de errores centralizado:** Uso de bloques `try / catch / finally` para una mejor mantenibilidad.
*   **Desestructuración de objetos (ES6):** Extracción limpia de datos (`name`, `email`, `company`) directamente del JSON de respuesta.
*   **Template Literals (ES6):** Inyección de HTML dinámico utilizando comillas invertidas ( `` ` `` ) y variables integradas `${ }`.

### Tecnologías
*   **HTML5:** Estructura semántica.
*   **CSS3:** Estilos en cuadrícula (Grid) y diseño responsivo corporativo.
*   **Vanilla JS (ECMAScript):** Lógica y comportamiento.
